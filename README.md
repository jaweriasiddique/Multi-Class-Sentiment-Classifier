# Intelligent Multi-Class Natural Language Text Sentiment Classifier

## Project Overview
This project is an NLP-based sentiment classification system that analyzes text reviews and classifies them into three categories: Positive, Negative, and Neutral.

## Objectives
- Analyze text using Natural Language Processing.
- Clean and preprocess text data.
- Convert text into numerical features using TF-IDF.
- Train a Logistic Regression classification model.
- Evaluate model performance using F1-score and a confusion matrix.
- Provide an interactive interface using Gradio.

## Technologies Used
- Python
- Google Colab
- Pandas and NumPy
- NLTK
- Scikit-Learn
- TF-IDF
- Logistic Regression
- Matplotlib and Seaborn
- Gradio

## Project Workflow
1. Dataset Loading
2. Text Preprocessing

5. Training and Testing

7. Sentiment Prediction
8. Model Evaluation
9. Gradio Interface

## Sentiment Categories

- Negative
